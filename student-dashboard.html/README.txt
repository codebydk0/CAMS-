CAMS FRONTEND PROTOTYPE
=======================

Files:
- index.html  : page structure and views
- style.css   : styles and responsive layout
- script.js   : menu navigation and local sample data/interactions

How to run:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in your browser.
3. No Node.js, npm, database, API, or backend is required.

Notes:
- This is a frontend-only prototype.
- Timetable, assignments, notices, notes, and marks are sample data.
- Notes' Download buttons show a message because no actual note files are included.
- Profile edits only update the current page/session and are not saved to a database.
- The current lecture uses the local device's time and the sample timetable.
- Font Awesome and Google Fonts are loaded from external CDNs; the rest of the app is local.
